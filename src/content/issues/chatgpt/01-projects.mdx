## 한 줄 요약

**프로젝트는 대화, 파일, 지침을 한곳에 모아 두는 작업 폴더입니다.** 프로젝트 안에서 시작하는 대화는 모두 같은 자료와 지침에 따라 답합니다.

## 일반 대화와 무엇이 다른가요?

| | 일반 대화 | 프로젝트 |
|---|---|---|
| 자료 | 대화할 때마다 다시 올림 | 한 번 올리면 모든 대화에서 사용 |
| 지침 | 매번 "이렇게 답해 줘"라고 다시 입력 | 프로젝트 지침으로 한 번만 설정 |
| 정리 | 대화 목록에 섞임 | 강의·연구별로 묶임 |

맞춤형 챗봇을 만드는 **GPT**는 다른 사람에게 배포할 때 적합합니다. 내 강의나 연구를 정리하는 데는 프로젝트가 더 간편합니다.

### 1. 강의별 프로젝트

**올릴 자료**: 강의계획서, 평가 루브릭, 주차별 강의 자료

```text
이 프로젝트는 「교육평가」 3학년 강의용이다. 업로드한 강의계획서와 루브릭을 기준으로 답한다.
과제 피드백은 루브릭 항목별로 강점 1개와 개선점 2개를 제시하고 격려하는 존댓말을 쓴다.
루브릭에 없는 기준은 임의로 만들지 않는다.
```

### 2. 연구 프로젝트

**올릴 자료**: 핵심 논문 PDF, 연구 노트

```text
업로드한 논문만 근거로 요약하고 비교한다. 주장마다 파일명과 쪽수를 밝히고
파일에 없는 내용은 "자료에 없음"이라고 쓴다. 새로운 참고문헌을 만들어 내지 않는다.
학술 문체의 한국어로 답한다.
```

### 3. 위원회·행정 업무 프로젝트

**올릴 자료**: 학칙, 관련 규정, 회의록 양식

```text
업로드한 학칙과 규정을 근거로 답하고 조항 번호를 인용한다. 회의록은 개조식(□, ○, -)으로 정리한다.
해석이 갈리는 부분은 단정하지 말고 "담당 부서 확인 필요"라고 표시한다.
```

## 꼭 지켜 주세요: 학생 개인정보

- **이름, 학번, 연락처, 성적이 들어간 파일은 올리지 마세요.** 꼭 필요하면 `학생A`처럼 가명으로 바꾼 뒤 올립니다.
- **개인 계정이라면 학습 사용을 끄세요.** Settings → Data Controls → **Improve the model for everyone** 을 끄면 대화와 파일이 모델 개선에 쓰이지 않습니다.
- **공유할 때는 "Only those invited"를 고르세요.** "Anyone with a link"로 열면 링크를 받은 사람은 누구나 들어올 수 있습니다.

## 알아 두면 좋은 점

- **파일 수 한도**: 프로젝트 하나에 무료는 5개, Plus는 25개, Edu·Pro는 40개까지 올릴 수 있습니다.
- **전체를 다 읽는다는 보장은 없습니다.** ChatGPT는 질문에 맞는 부분을 찾아 읽습니다. 중요한 답변은 원문과 대조해 확인하세요.
- **문서 속 그림과 표 이미지는 읽지 못할 수 있습니다.** 스캔한 PDF보다 텍스트가 살아 있는 파일이 좋습니다.
- **인용과 참고문헌은 지어낼 수 있습니다.** 논문에 쓰기 전에 반드시 원문을 확인하세요.
- **기억 범위**: 프로젝트를 만들 때 **기본 메모리** 메뉴에서 **프로젝트 전용 메모리**를 고르면 이 프로젝트 안의 대화만 참고합니다. 강의 자료와 개인 대화가 섞이지 않게 하고 싶을 때 쓰세요. 나중에 바꾸지 못할 수 있으니 만들 때 정해 두세요.
