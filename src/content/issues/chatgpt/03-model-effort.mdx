## 모델에 따라 얼마나 쓸 수 있나요?

**같은 일반 좌석이라도 모델에 따라 사용 가능한 메시지 수가 크게 달라집니다.**

| 모델 | 5시간당 메시지 추정치 | 이렇게 사용하세요 |
|---|---:|---|
| **GPT-6 Luna** | **350~3,000회** | 짧은 요약·항목 추출을 자주 할 때 |
| **GPT-6.1 Terra** | **35~285회** | 안내문 작성·일상 문서 작업 |
| **GPT-6.1 Sol** | **15~160회** | 여러 자료 분석·복잡한 조건 검토 |
| **GPT-6 Astra** | **5~45회** | Sol로 해결하기 어려울 때 제한적으로 |

**일상 업무는 Terra·Sol, 간단한 반복 작업은 Luna부터 시작하세요.** Astra를 계속 쓰면 사용 한도에 빨리 도달할 수 있습니다.

<small>OpenAI의 Standard Business **로컬 메시지** 공식 추정치입니다. 웹에서 보장되는 질문 횟수가 아니며 클라우드 작업은 더 많이 소모할 수 있습니다. 모델별로 별도 횟수를 받는 것이 아니라 같은 사용 한도를 나누어 씁니다. effort·자료 양·도구 사용에 따라 달라지고 주간 한도도 적용될 수 있습니다. [공식 사용량 안내](https://learn.chatgpt.com/docs/pricing)</small>

## 1. 모델과 effort는 무엇이 다른가요?

| 설정 | 뜻 | 선택할 때 생각할 것 |
|---|---|---|
| **모델** | 작업을 맡길 AI의 종류 | 간단한 정리인가요, 복잡한 판단인가요? |
| **effort(추론 강도)** | 선택한 모델이 문제를 풀 때 얼마나 많은 추론을 할지 조절 | 빠른 초안이면 되나요, 여러 조건을 꼼꼼히 따져야 하나요? |

effort를 높여도 다른 모델로 바뀌지는 않습니다. **답변 길이를 정하는 설정도 아닙니다.** 화면에 짧은 답이 나와도 내부 추론에 사용량을 쓸 수 있습니다.

OpenAI는 높은 effort가 복잡한 작업에 도움이 될 수 있지만 시간이 더 걸리고 토큰도 더 쓴다고 설명합니다. **토큰**은 AI가 글을 읽고 생성할 때 처리하는 작은 단위입니다. 모델·추론·자료 양·도구 사용 등이 한도 소모에 함께 영향을 줍니다. [공식 모델 안내](https://learn.chatgpt.com/docs/models) · [사용량 안내](https://learn.chatgpt.com/docs/pricing)

## 2. 더 많이 생각하면 항상 더 정확할까요?

**이미 충분히 풀 수 있는 문제에서는 effort를 높여도 정확도가 그대로일 수 있습니다.**

Srivastava 외 연구진의 <em>Do LLMs Overthink Basic Math Reasoning?</em>은 정렬·덧셈 등 14종의 기본 수학 과제로 모델을 평가했습니다. GPT-5의 결과는 다음과 같습니다.

| GPT-5 effort | 정확도 |
|---|---:|
| Low | 96% |
| Medium | 97% |
| High | 97% |

**이 평가에서는 Medium에서 High로 올려도 정확도가 높아지지 않았습니다.** 다만 기본 수학 과제의 결과이며 현재 Work 모델이나 논문 분석·글쓰기 성능을 측정한 것은 아닙니다. 어려운 문제에서도 높은 effort가 불필요하다는 뜻은 아닙니다.

<small>출처: 논문 v3(2026-04-23), 부록 L 표 9. 표에 보고된 평균 정확도이며 통계적 동등성을 뜻하지 않습니다. 논문의 토큰 수치는 응답 길이를 측정하므로 숨겨진 추론을 포함한 전체 과금량이나 Work 한도 절감률로 환산하지 않았습니다. [논문 원문과 표 9](https://arxiv.org/html/2507.04023v3#A12)</small>

## 3. 내 작업에는 무엇을 고르면 될까요?

다음은 [OpenAI의 모델 선택 안내](https://learn.chatgpt.com/docs/model-selection)를 바탕으로 정리한 출발점입니다. 계정에서 선택할 수 있는 모델을 사용하세요.

| 작업 | 시작할 모델과 effort |
|---|---|
| 회의 메모에서 할 일 추출, 짧은 요약 | **Luna**, 기본 설정부터 시작 |
| 제공한 자료로 안내문 작성, 이미지 설명 | **GPT-6.1 Terra**, 기본 설정 |
| 여러 자료를 묶어 수업 계획 초안 작성 | **GPT-6.1 Sol**, 기본 또는 Medium |
| 서로 충돌하는 근거 비교, 복잡한 조건 검토 | **GPT-6.1 Sol**, 기본 설정에서 필요하면 effort 상향 |

**모델과 effort를 한꺼번에 최고로 올리기보다, 부족한 부분을 보고 하나씩 바꿔 보세요.** 상위 모델이 재작업을 줄여 더 효율적일 때도 있습니다. 같은 이름의 effort라도 모델마다 결과와 사용량이 같지는 않습니다.

**기본**은 추천 모델 세트입니다. 기본 상태의 슬라이더에서는 모델과 추론 수준이 함께 바뀔 수 있으므로, effort만 비교하려면 먼저 특정 모델을 고르세요. 익숙한 작업에서 **필수 정보 누락, 사실 오류, 수정에 걸린 시간**을 확인하고 결과가 충분하면 설정을 유지합니다.

**직접 해 보기 — 교육용 예시**

공개된 행사 안내문을 넣고 “일시·장소·신청 기한을 표로 정리해 줘. 원문에 없는 정보는 ‘확인 필요’로 표시해 줘.”라고 요청해 보세요. 기본 설정으로 정확하게 정리됐다면 effort를 더 높일 필요가 없습니다.

결과가 부족하면 먼저 **원문과 요청 조건이 충분한지** 확인하세요. 복잡한 비교나 추론에서 막힐 때 설정을 높입니다. 모든 작업을 두 번 실행할 필요는 없습니다. 자주 하는 작업 하나로 비교해 두면 됩니다.
