## 작업 폴더를 연결하고 대화 시작하기

**① 앱을 설치하고 로그인하세요.**

[ChatGPT 데스크톱 앱 설치 안내](https://learn.chatgpt.com/ko-KR/docs/app)에서 앱을 설치한 뒤 학교 ChatGPT Business 계정으로 로그인하세요. 웹에서 Work를 쓰고 있다면 입력창 아래 **데스크톱 앱 열기**를 누르세요.

<figure>
  <ClickTarget src={siteUrl('images/chatgpt/04-local-folder/start.png')} alt="Work 입력창 아래 프로젝트 선택과 데스크톱 앱 열기 버튼" loading="lazy" bounds={[79, 71, 17.5, 17]} />
  <figcaption>ChatGPT 웹의 Work 입력창. 오른쪽 아래에서 데스크톱 앱을 열 수 있습니다.</figcaption>
</figure>

**② 작업할 폴더를 선택하세요.**

폴더를 고르기 전에 안에 든 자료를 확인하세요. ChatGPT는 하위 폴더도 열 수 있으므로 연구 참여자의 개인정보가 담긴 자료는 연결할 폴더 밖에 보관하세요.

1. 데스크톱 앱에서 **프로젝트** 목록을 여세요.
2. 내 컴퓨터의 폴더를 연결하려면 **로컬 프로젝트**를 추가하세요.
3. 폴더 선택 창에서 원고를 보관한 폴더를 고르세요. 아래 실습에서는 `논문` 폴더를 씁니다.

이미 로컬 프로젝트가 있다면 해당 프로젝트 메뉴에서 **프로젝트 편집 → 폴더 추가**를 선택하세요. [OpenAI 폴더 연결 안내](https://learn.chatgpt.com/ko-KR/docs/projects)

**③ 읽을 자료와 원하는 결과를 알려 주세요.** 연결한 프로젝트에서 새 채팅을 열고 **Work**를 선택하세요. 작업 위치를 물으면 내 컴퓨터에서 작업하는 **Local**을 고르세요. 어느 파일이나 하위 폴더를 읽을지 이름을 적어 주세요. 결과를 파일로 남기려면 저장할 폴더와 파일 이름도 알려 주세요.

## 실습 · 내 논문을 읽고 질문해 보기

위 단계에서 연결한 폴더로 실습해 보세요. 아래 화면에서는 원고와 참고 자료가 든 `논문` 폴더를 골랐습니다.

  <ClickTarget src={siteUrl('images/04-local-folder/folder.png')} alt="현재 위치가 논문이고 목록에 선행연구 하위 폴더가 보이는 macOS 폴더 선택 창" loading="lazy" bounds={[85.8, 89.8, 12, 6.2]} />
  <figcaption>macOS에서는 창 위쪽의 폴더 이름을 확인한 뒤 오른쪽 아래 ‘선택’을 누르세요.</figcaption>

원고를 쓰면서 궁금했던 점을 하나 물어보세요. 서론을 다듬는 중이라면 아래 예시에서 ‘논문 초안’을 실제 파일 이름으로 바꿔 보세요.

> **교육용 예시** · “‘논문 초안’의 서론을 읽어 줘. 독자가 이 글에서 답하려는 연구 질문을 한 문장으로 짚어낼 수 있을까?”

답을 읽고 남겨 둘 내용이 있다면 같은 대화에서 이어서 요청하세요.

> **교육용 예시** · “방금 짚어 준 내용과 서론에서 고칠 점을 한글 문서로 정리해 줘. 원고와 같은 폴더에 ‘서론 검토 메모.hwpx’로 저장해 줘.”

원고 폴더에서 ‘서론 검토 메모.hwpx’를 한글로 열어 검토 내용이 담겼는지 확인하세요. 파일이 생기지 않거나 열리지 않으면 대화에 정리한 내용을 한글의 새 문서에 붙여 넣고 HWPX로 저장하세요.
