## 작업 폴더를 연결하고 대화 시작하기

**① 앱을 설치하고 로그인하세요.**

[Claude 데스크톱 앱 설치 안내](https://claude.com/download)에서 앱을 설치한 뒤 학교 Claude Team 계정으로 로그인하고 새 대화를 여세요. [Anthropic 화면 안내](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude)

**② 아래 화면처럼 입력창 밑에 ‘프로젝트 또는 폴더’가 보이면 바로 누르세요.**

입력창에 **Chat / Cowork**가 따로 보일 때만 **Cowork**를 먼저 고르세요.

<figure>
  <ClickTarget src={siteUrl('images/claude/04-local-folder/start.png')} alt="입력창 왼쪽 아래에 있는 ‘프로젝트 또는 폴더’ 버튼과 펼침 화살표" loading="lazy" bounds={[4.2, 73, 18.8, 16]} />
  <figcaption>입력창 아래 왼쪽의 ‘프로젝트 또는 폴더’를 누르면 선택 메뉴가 열립니다.</figcaption>
</figure>

폴더를 고르기 전에 안에 든 자료를 확인하세요. Claude는 하위 폴더도 열 수 있으므로 연구 참여자의 개인정보가 담긴 자료는 연결할 폴더 밖에 보관하세요.

메뉴에서 내 컴퓨터의 폴더를 여세요. 선택 창이 뜨면 작업할 폴더를 고르고 접근을 허용하세요. 파일을 읽는 동안에는 데스크톱 앱을 열어 두세요. [Anthropic 폴더 접근 안내](https://support.claude.com/en/articles/15520349-use-claude-cowork-on-web-desktop-and-mobile)

**③ 읽을 자료와 원하는 결과를 알려 주세요.** 폴더 접근을 허용한 뒤 같은 대화에서 요청을 이어 가세요. 어느 파일이나 하위 폴더를 읽을지 이름을 적어 주세요. 결과를 파일로 남기려면 저장할 폴더와 파일 이름도 알려 주세요.

## 실습 · 내 논문을 읽고 질문해 보기

위 단계에서 연결한 폴더로 실습해 보세요. 아래 화면에서는 원고와 참고 자료가 든 `논문` 폴더를 골랐습니다.

<figure>
  <ClickTarget src={siteUrl('images/04-local-folder/folder.png')} alt="현재 위치가 논문이고 목록에 선행연구 하위 폴더가 보이는 macOS 폴더 선택 창" loading="lazy" bounds={[85.8, 89.8, 12, 6.2]} />
  <figcaption>macOS에서는 창 위쪽의 폴더 이름을 확인한 뒤 오른쪽 아래 ‘선택’을 누르세요.</figcaption>
</figure>

원고를 쓰면서 궁금했던 점을 하나 물어보세요. 서론을 다듬는 중이라면 아래 예시에서 ‘논문 초안’을 실제 파일 이름으로 바꿔 보세요.

> **교육용 예시** · “‘논문 초안’의 서론을 읽어 줘. 독자가 이 글에서 답하려는 연구 질문을 한 문장으로 짚어낼 수 있을까?”

답을 읽고 남겨 둘 내용이 있다면 같은 대화에서 이어서 요청하세요.

> **교육용 예시** · “방금 짚어 준 내용과 서론에서 고칠 점을 한글 문서로 정리해 줘. 원고와 같은 폴더에 ‘서론 검토 메모.hwpx’로 저장해 줘.”

원고 폴더에서 ‘서론 검토 메모.hwpx’를 한글로 열어 검토 내용이 담겼는지 확인하세요. 파일이 생기지 않거나 열리지 않으면 대화에 정리한 내용을 한글의 새 문서에 붙여 넣고 HWPX로 저장하세요.
